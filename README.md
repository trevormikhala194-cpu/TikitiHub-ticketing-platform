# TikitiHub-ticketing-platform
A full-stack event ticketing and management platform built with Django REST Framework, React, and PostgreSQL, featuring secure authentication, online ticket booking, QR code validation, and M-Pesa payment integration.
# TikitiHub

A modern, secure, and scalable event ticketing platform built with **Django REST Framework** and **React**. TikitiHub is designed to simplify ticket sales, event management, and attendee experiences for concerts, conferences, festivals, sports events, and other major events across Kenya.

---

## Project Overview

TikitiHub enables event organizers to create and manage events while allowing attendees to discover, purchase, and manage digital tickets securely.

The platform focuses on:

- Event management
- Secure online ticket purchasing
- QR Code ticket validation
- Role-based access control
- Online payments
- Organizer dashboard
- Real-time notifications
